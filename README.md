# movie-recommender
A simple movie recommendation system written in Python.

## Overview

This project recommends movies to users based on similarities between user preferences. It demonstrates fundamental programming concepts such as data structures, functions, file handling, and recommendation logic.

## Features

- User-based movie recommendations
- Similarity calculation between users
- JSON data storage
- Command-line interaction
- Easy to extend and improve

## Technologies Used

- Python
- JSON
- Sets and Dictionaries
- Basic Recommendation Algorithms

## Learning Objectives

This project was developed as part of my journey toward Machine Learning and Artificial Intelligence. It helped me practice Python programming, problem-solving, and algorithmic thinking.
